# GERS STYLES project guidance

- Keep the project dependency-free unless a future request explicitly approves a dependency.
- Use plain HTML, CSS, and JavaScript.
- Preserve the existing project structure.
- Do not introduce brand decisions beyond those provided by the project owner.
- Keep shared tokens and reusable component foundations in `css/style.css`.
- Use the established GERS color custom properties; do not add new colors without approval unless accessibility requires it.
- Add page-specific styles separately from the design-system sections in `css/style.css`.
